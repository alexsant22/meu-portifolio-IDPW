FaceShield

Conheça o Face Shield, a solução definitiva para o controle de ativos e monitoramento de usuários dentro do ambiente de aprendizado. Com o Face Shield, você tem visão completa de quais ferramentas estão disponíveis, onde cada item está guardado e quem é o responsável por cada empréstimo, tudo validado por biometria facial.

ColabManager

Sistema FullStack em desenvolvimento para gerenciamento de funcionários, utilizando Java, Spring Boot, MySQL e JPA para o back-end, e ReactJS para o front-end. O sistema permite cadastrar, editar, excluir e listar funcionários, além de fornecer relatórios de desempenho e estatísticas sobre a equipe. O objetivo do projeto é aprimorar minhas habilidades em desenvolvimento web e criar uma aplicação prática para gerenciar informações de funcionários de forma eficiente e intuitiva.
